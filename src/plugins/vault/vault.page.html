Hardware-encrypted credential vault with OnlyKey

Store API keys and secrets encrypted by your OnlyKey. Encryption keys are derived on the device, and only ciphertext is stored, in this browser.

How your secrets are encrypted
  • On the OnlyKey: for each service name the device derives a P-256 (secp256r1) key from its web-derivation key, a random 32-byte key generated on the OnlyKey, using HKDF-SHA256 over SHA-256("vault:" + service name). The private key never leaves the OnlyKey.
  • Unlock: the OnlyKey computes a P-256 ECDH shared secret with that key and returns it over the encrypted OnlyKey connection. Unlocks follow the OnlyKey's web and agent derived key setting: a tap by default, or the challenge code shown below, or no confirmation if you turned it off.
  • In this browser: HKDF-SHA256 turns the shared secret into a non-exportable AES-256-GCM key (WebCrypto). Each secret is encrypted with a fresh random 96-bit nonce, and only the ciphertext is stored (IndexedDB). Unlocked keys stay in memory for the session time you choose, until Lock all sessions or the page closes.
  • Recovery: the same OnlyKey and service name always give the same key, so an exported vault opens on any computer with that OnlyKey, or with a key restored from its backup.
